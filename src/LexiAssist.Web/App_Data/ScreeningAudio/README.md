# Screening audio files

Place administrator-managed listening comprehension audio files in this folder. In a question's Audio file name field, enter only the file name, for example `story.mp3`.

Supported extensions are MP3, WAV, OGG, M4A, AAC, and WebM. Files are streamed through the authenticated screening route rather than served as public static files. Each file must be non-empty and no larger than 100 MB. Do not place personal recordings or other sensitive material here.

The repository includes `development-listening-blue-bird.wav` as a neutral, development-only speech fixture. It is used by the local development listening verification path and must not be treated as clinical or production content.
